# RudStock API

Общие правила:
- деньги везде в копейках, `int64` (149.99 ₽ → `14999`)
- id карточки: UUID строкой; id категории: целое число
- ошибка всегда в формате `{"slug": "category-not-found", "msg": "Category not found"}`; `slug` стабильный машинный код, `msg` текст для пользователя
- доступ: `public` без авторизации, `admin` только админ (все ручки под `/admin/*`)
- стиль REST: путь называет ресурс во множественном числе, действие задаёт HTTP-метод

## Админка

### POST /admin/cards

Создание карточки товара.

Доступ: `admin`

Запрос:
```json
{
  "category_id": 1,
  "description": "Шина летняя 205/55 R16",
  "price": 14999,
  "photo_url": "s3://photos/photo_1.jpg"
}
```

| Поле | Тип | Обязательно | Правила |
|---|---|---|---|
| category_id | int64 | да | категория должна существовать |
| description | string | нет | |
| price | int64 | да | > 0, копейки |
| photo_url | string | нет | ссылка на объект в minio |

Ответ `201`:
```json
{ "card_id": "3f2b8c1e-6a1d-4c2e-9b7a-2d5f0e8a1c44" }
```

Ошибки:
| Код | Когда |
|---|---|
| 400 | невалидный JSON, category_id не передан (<= 0), price <= 0 |
| 404 | категория не найдена |
| 500 | всё остальное |

---

### PATCH /admin/cards/{id}

Частичное обновление карточки: меняются только переданные поля.

Доступ: `admin`

Запрос (любое подмножество полей, хотя бы одно):
```json
{ "price": 12999, "description": "Шина летняя 205/55 R16, распродажа" }
```

| Поле | Тип | Обязательно | Правила |
|---|---|---|---|
| category_id | int64 | нет | > 0, категория должна существовать |
| description | string | нет | можно `""`, чтобы очистить |
| price | int64 | нет | > 0, копейки |
| photo_url | string | нет | можно `""`, чтобы очистить |

Поле отсутствует или `null` → не меняется. Неизвестное поле → 400.

Ответ `200`: карточка целиком после изменения, формат как у `GET /cards/{id}`.

Ошибки:
| Код | Когда |
|---|---|
| 400 | `id` не UUID, невалидный JSON, ни одного поля (`empty-patch`), category_id <= 0, price <= 0 |
| 404 | карточки нет (`card-not-found`), новой категории нет (`category-not-found`) |
| 500 | всё остальное |

---

### DELETE /admin/cards/{id}

Удаление карточки. Пока физическое: заказов ещё нет. Когда появятся, станет архивированием (`status`), а для карточки в заказах вернёт 409.

Доступ: `admin`

Ответ `204` без тела.

Ошибки:
| Код | Когда |
|---|---|
| 400 | `id` не UUID (`invalid-path-param`) |
| 404 | карточки нет (`card-not-found`) |
| 500 | всё остальное |

---

### POST /admin/categories

Создание категории.

Доступ: `admin`

Запрос:
```json
{ "name": "Шины" }
```

| Поле | Тип | Обязательно | Правила |
|---|---|---|---|
| name | string | да | не пустое, уникальное |

Ответ `201`:
```json
{ "category_id": 1 }
```

Ошибки:
| Код | Когда |
|---|---|
| 400 | невалидный JSON, пустое имя |
| 409 | категория с таким именем уже есть |
| 500 | всё остальное |

---

### DELETE /admin/categories/{id}

Удаление пустой категории. Если в ней есть карточки, сначала их нужно перенести (`PATCH /admin/cards/{id}` с новым `category_id`) или удалить.

Доступ: `admin`

Ответ `204` без тела.

Ошибки:
| Код | Когда |
|---|---|
| 400 | `id` не целое число (`invalid-path-param`) |
| 404 | категории нет (`category-not-found`) |
| 409 | в категории есть карточки (`category-has-cards`) |
| 500 | всё остальное |

## Публичные

### GET /categories

Список всех категорий, по алфавиту. Без пагинации: категорий единицы.

Доступ: `public`

Ответ `200`:
```json
[
  { "id": 1, "name": "Диски" },
  { "id": 2, "name": "Шины" }
]
```

Категорий нет → `[]`.

Ошибки:
| Код | Когда |
|---|---|
| 500 | всё остальное |

---

### GET /cards

Список карточек, новые первыми, с пагинацией.

Доступ: `public`

Query-параметры:
| Параметр | Тип | Обязательно | Правила |
|---|---|---|---|
| category_id | int64 | нет | >= 0; нет или `0` → все категории; несуществующая → пустой список |
| page | int | нет | >= 0, с 1; нет или `0` → `1` |
| limit | int | нет | >= 0; нет или `0` → `20`; больше `100` → `100` |

Пример: `GET /cards?category_id=2&page=1&limit=20`

Ответ `200`:
```json
{
  "items": [
    {
      "id": "3f2b8c1e-6a1d-4c2e-9b7a-2d5f0e8a1c44",
      "category_id": 2,
      "description": "Шина летняя 205/55 R16",
      "price": 14999,
      "photo_url": "s3://photos/photo_1.jpg",
      "created_at": "2026-09-30T12:00:00Z"
    }
  ],
  "total": 1
}
```

`total` это число карточек под фильтром без учёта пагинации. Страница за концом списка → `items: []`, `total` прежний.

Ошибки:
| Код | Когда |
|---|---|
| 400 | параметр не целое число, отрицательный `category_id`, `page` или `limit` |
| 500 | всё остальное |

---
